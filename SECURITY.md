# Security policy

## Supported versions

Only the latest 0.x release receives security fixes. Please update to it before reporting an issue.

## Reporting a vulnerability

Do not open a public issue, pull request or discussion for a security vulnerability.

Report it privately with GitHub's private vulnerability reporting: open <https://github.com/JtheGunner/doc-drift-checker/security/advisories/new> (the "Report a vulnerability" button on the repository's Security tab).

Please include:

- the affected version and platform,
- a description of the problem and its impact,
- steps or a minimal repository to reproduce it.

## What to expect

- An acknowledgement within 7 days.
- An assessment and a first answer within 14 days.
- A fix and a coordinated disclosure through a GitHub security advisory once a patched release is available.

This is a volunteer-maintained project, so these are targets, not guarantees.
